# LLM-AGI Papers

The following is a list of interesting resources that speculate about the limits of LLMs. These are the sources I referenced in the presentation.

 - [How Close is AGI Actually? - Tom Villani](https://www.njii.com/2024/07/why-llms-alone-will-not-get-us-to-agi/)
 - [Why LLMs aren’t AGI and We need a new Qualitative Model - Chris Hood](https://chrishood.com/why-llms-arent-agi-and-we-need-a-new-qualitative-model/)
 - [The Illusion of Thinking: Understanding the Strengths and Limitations of Reasoning Models via the Lens of Problem Complexity - Parshin Shojaee, Iman Mirzadeh, Keivan Alizadeh, Maxwell Horton, Samy Bengio, Mehrdad Farajtabar](https://arxiv.org/abs/2506.06941)
