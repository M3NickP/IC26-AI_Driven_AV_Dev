# AI Driven AV Development Workflows - InfoComm 2026

Presented By Nick Paton at M3 Technology Group Inc.

This repository contains the code and resources for the presentation as well as supplemental documents and links.

## Presentation

The links and resources used in the presentation are available in the [links](links/presentation-links.md) file.

The presentation itself contains a lot of video and animation, so it is not feasible to include it in this repository.

Be on the lookout for a recorded version of the presentation in the near future.


## Example Project

The example project used in the presentation is available in the [examples](examples/qsys-qrwc-example) directory.

The exact prompts used in the presentation are available in the [Example Prompts](examples/example-prompts.md) file.

See the [README](examples/qsys-qrwc-example/README.md) file for more information on the example project. and for setup instructions.

The completed example project is available by checking out the `ui-changes` branch. (`git checkout ui-changes`)


## Additional Resources

The [av-vendor-guidance](av-vendor-guidance) directory contains additional resources for specific av vendors. 

These vendor specific resources provide general strategies that can be used to enhance the capabilities of AI agents when working with specific AV vendors.
